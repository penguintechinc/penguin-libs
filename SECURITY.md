# Security Policy

## Reporting Security Vulnerabilities

Penguin Tech takes security seriously. If you discover a security vulnerability in this project, please **report it privately** rather than using the public issue tracker.

**Contact:** support@penguintech.io

## Reporting Process

1. **Report privately** to support@penguintech.io with:
   - Description of the vulnerability
   - Steps to reproduce (if applicable)
   - Affected versions
   - Potential impact

2. **Response SLA:** We aim to acknowledge receipt within 2 business days and provide an initial assessment within 5 business days.

3. **Confidentiality:** We will keep the vulnerability confidential during the patching and release process and give you credit in the security advisory if desired.

## Supported Versions

For version support and security patch information, see [PACKAGE_PUBLISHING_STATUS.md](PACKAGE_PUBLISHING_STATUS.md).

## Security Updates

Security patches are released as soon as they are available. Users should:
- Monitor GitHub releases and security advisories
- Update to the latest patched version promptly
- Review [CHANGELOG.md](CHANGELOG.md) for security-related fixes

## Scope

This security policy applies to:
- All packages published by Penguin Tech under the `@penguintechinc/` npm scope
- All Python packages published to PyPI (penguin-*, etc.)
- All Go modules published from this repository
- All Dart/Flutter packages published to pub.dev

## Disclaimer

This software is provided as-is. Penguin Tech makes reasonable efforts to identify and patch security vulnerabilities, but cannot guarantee the absence of defects or vulnerabilities. For production deployments, users are responsible for security hardening and risk mitigation.
